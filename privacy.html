Privacy Policy

Last updated: 10 November 2026

This policy explains how the Lead Generation application ("the app") uses data from Google accounts.

Who uses the app

The app is a private tool used only by its owner. It runs on the owner's own computer. No other users can sign in, and no one else's Google account is connected to it.

What Gmail access is used for

The app connects to Gmail only so that the owner can:

  • send the owner's own emails from the owner's own Gmail account;
  • read replies in those email threads, so the owner can see responses and continue the conversation.

The app does not use Gmail data for advertising, profiling, or any purpose other than the ones listed above.

How data is stored

Email content and access tokens are stored only on the owner's computer. They are not uploaded to any server operated by the app.

Sharing

Data is not shared with anyone. It is not sold, rented, or transferred to third parties. The only exception is that the owner may use an AI service to help draft the owner's own email replies; this is done on the owner's behalf and not for any other purpose.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from the Google account's third-party access settings. Deleting the app's local files removes all stored data.

Changes

If this policy changes, the updated version will be published on this page.
